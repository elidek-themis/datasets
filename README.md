## Bias Evaluation Datasets

This repository provides details for various datasets used for evaluating bias in language models that are available in the related work. The taxonomy is based on the work of Isabel O Gallegos et al. [“Bias and fairness in large language models: A survey”](https://arxiv.org/abs/2309.00770). It also provide details about datasets that are used for evaluating bias in graphs from social networks, the web and other networks.
